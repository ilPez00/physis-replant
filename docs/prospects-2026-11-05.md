## Manual first message

Personalize the bracketed line; send only through an appropriate public business
route and respect platform rules and refusals. Nothing here sends messages.

> Hi [name], I found your [specific n8n template/service]. I built Replant, an
> Apache-2.0 tool that records a checked tool recipe and reruns the real actions
> and checks without asking an LLM to plan the identical task again.
>
> Would you be open to feedback on a read-only scan of one sanitized workflow?
> It separates measured token usage from optimization candidates and produces
> local scan receipts. No workflow execution or claimed savings from the scan.
>
> Code and scoped benchmark: https://github.com/ilPez00/physis-replant

If there is interest, agree scope, data handling, and acceptance checks before
requesting exports or API access. An audit at €190 or a €500–€1,000 fixed-scope
pilot is a proposed offer to validate, not established pricing or demand.
The published 99% token reduction is one exact-repeat n8n benchmark, not a
guaranteed customer bill reduction. A fixed workflow may not need an LLM at all.
